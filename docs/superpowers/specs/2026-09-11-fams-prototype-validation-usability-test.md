# FAMS 第5步：设计稿功能覆盖验证

> 版本：UT V1.1 · 2026-09-12  
> 验证对象：D0.4 高保真设计稿与本地静态原型  
> 功能基线：[PRD V1.5](2026-09-03-fixed-asset-product-design.md)  
> 流程与页面基线：[IA D0.2](2026-09-06-fixed-asset-ia-interaction-design.md)  
> 核对清单：[功能覆盖记录](2026-09-11-fams-usability-test-matrix.csv)  
> 结论：`COMPLETED`，未发现 PRD V1.5 一期功能遗漏。

## 1. 验证方式

本项目采用轻量验证。第5步只回答一个问题：**D0.4 设计稿是否覆盖功能设计文档中的全部一期功能？**

不再组织15～22名用户、访谈、R0/R1/R2或多轮可用性测试。流程顺不顺、操作是否还能提效，由系统上线后的真实反馈驱动，在二期、三期继续优化。

通过标准：

1. PRD V1.5 的 `AC-01～AC-53` 每项都有流程或页面映射；
2. IA D0.2 的 `F01～F10`、`P01～P26`、`M01～M14` 均存在；
3. D0.4 设计稿具备全部40个页面；
4. 没有发现只能在PRD中找到、却没有任何设计入口或承载页面的一期功能。

## 2. 核对输入

- [IA D0.2](2026-09-06-fixed-asset-ia-interaction-design.md)：10条业务流程、40页设计清单及 `AC-01～AC-53` 追溯表。

## 5. 结论与边界

按当前验收口径，D0.4 设计稿已覆盖 PRD V1.5 的全部一期功能，第5步完成，可以在收到开发指令后进入第6步。

本结论只证明“功能在设计中有入口、有页面或有状态承载”，不证明：

- 前后端、接口、权限、并发或离线能力已经实现；
- 真实用户使用效率已经达到统计指标；
- 性能、安全、兼容性或生产环境已经通过QA；
- 二期、三期流程优化已经完成。

后续只有两种情况需要重新打开本检查：PRD V1.5发生范围变更，或开发时发现某项功能没有足够的页面/状态设计。其他体验改进收集到二期、三期，不阻塞一期开发。
