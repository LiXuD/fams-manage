## 使用方式

浏览器直接打开 `index.html` 即可使用，无安装、账号、网络或外部资源依赖。画布外的目录与情境控件用于评审；画布内为拟议产品页面。示例人名、资产、数字均为虚构；刷新重置本地演示状态。

使用本地HTTP预览时，可从项目根目录运行：

```sh
rtk proxy python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/superpowers
```

浏览器打开 `http://127.0.0.1:8765/prototypes/2026-09-06-fixed-asset/index.html`。这个临时预览服务只用于查看设计；直接打开文件不需要该服务。停止对应服务进程即可结束预览。

## 推荐走查

1. **领用**：P09重置示例 → 批准 → P10开始处理 → P12分配2件/无法满足1件 → 记录交出 → M09先选择任一件接收，再接收另一件 → M04部分完成。可在顶部切换7种情境，核对当前步骤与数量。
2. **资产历史**：P04逐一切换九页签，确认当前资产不变；领借调拨和操作日志有内联记录，无维修/报失记录的页签为明确空态。打开原单需另行点击。
3. **交接异常**：P21申请代确认 → 管理员P09决定 → P21当前库管执行 → M13责任通知；仅批准不代表执行，成功后不要求员工再次接收。
4. **现场差异**：M11在账面房间302核实；切换至301并确认，账面仍为302，主操作改为保存位置差异。
5. **离线边界**：M12画布外逐一选择正常、封存后T+71h、T+72h过期、身份失效、过期后重试旧成功回执、时间异常、旧分配证据。观察单条回执与计数。封存情境下返回M11无新采集入口；身份失效时不展示原资产证据。
6. **差异复核**：P16转正式调拨后仍为处理中；另一责任差异未关闭；查看旧页面冲突反馈。
7. **处置和权限**：P20选择遗失核销，当前无确认遗失依据时不能提交；P02默认业务角色无系统配置菜单，P25系统管理员只展示配置导航。

## 原型边界

- 主链和选定分支具有本地状态反馈，其余表单、上传、打印及列表筛选展示结构或说明；不是全部业务功能已实现。
- 离线评审每次选情境重置一组示例，重点展开一条事件。未实现真实缓存、服务端权限、时钟、并发裁决或微信能力。
- P02与P23汇总/抽样为固定虚构值，不随领用情境联动；不会访问真实资产数据。
- 原PRD及外部审查原文保留。当前目录不是Git仓库，本次未提交或推送。
