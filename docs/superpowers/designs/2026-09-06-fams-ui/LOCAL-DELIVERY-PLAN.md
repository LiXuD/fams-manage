# D0.3 本地 UI 设计交付计划

> 历史计划：本文件记录D0.3本地UI交付范围，任务已完成，不是当前待办。D0.4设计终态见[HANDOFF-D0.4](HANDOFF-D0.4.md)，项目当前阶段见[根交接入口](../../../../DESIGN-HANDOFF.md)。

用户已明确：沿用既有设计文件的风格，Figma 插件没有额度，继续完成本地视觉设计、组件库与设计系统。Figma 回填与 Mobbin 不再是完成条件。

已接受的视觉基线：浅色冷灰画布、白色内容面、深蓝主操作、独立的成功/注意/危险色、中文优先、PC 密集表格与小程序现场操作分工。继续使用现有 D0.3 的视觉风格，不重新制作其他概念方向。

## 本轮交付

1. 组件系统：8 个主要组件族的完整状态实例、可复用 DOM/CSS 构造器、属性与变体清单；补齐 D0.2 用到的选择、弹窗、步骤、时间线和进度组合。
2. 基础规范：56 个基础变量；8 个文字样式的机器可读值及 CSS；阴影、动效、布局、安全区、焦点与状态规则。
3. 页面应用：保留 40 页及 D0.2 业务状态机，增加独立画布预览；按页面编号提供截图与组件映射。
4. 验证：组件状态及交互、PC/移动视口、焦点/边界/对比度、关键接收与盘点负面情境、截图与基线视觉比较。
5. 交接：更新 README、规范、验证、目标审计与开发使用说明；本地设计交付完成后明确历史 Figma 文件只是来源快照。

## 边界

这是 UI 设计交付，不开发真实服务、权限、短信、相机、缓存或并发控制。不把原型中的结构示例改称生产功能。原 D0.2 不修改；画布外评审工具不进入产品界面。截图和节点记录属于设计证据，保留在项目交付目录及现有 output/playwright 路径。

验证路径：规范页 → 组件状态/交互 → 40 页画布 → 接收确认/未选拦截 → 房间差异/离线回执。Browser 专用 skill 不在当前目录，沿用已安装 Playwright CLI，不安装新依赖。
