FAMS 界面设计完善 · 状态色板与移动优先布局

基于设计团队 D0.3（浅色深蓝 / fams- 令牌 / 85 组件变体）。本页在两处 PRD 明确要求而 D0.3 尚未覆盖的点上做加法：① 资产 11 状态色板（PRD §7.1 要求生命周期 + 异常全部「文字+颜色」双通道，而 D0.3 Status 仅 5 档）；② 移动优先布局系统（PRD 明确移动优先，D0.3 视觉层以 max-width 桌面优先实现）。其余完全沿用团队组件与令牌。

① 现状对照：D0.3 的 Status 组件（5 档）

组件库 Status 仅 Neutral / Info / Success / Warning / Danger。以下为团队原样（index.html 摘录）。生命周期与异常状态超过 5 种时，只能复用相近色调，导致「在库=借出」「维修中=查找中」等无法区分。

② 完善一：完整 11 状态资产色板

⑤ 如何并入 D0.3

三步合并，不改任何已渲染页面

1. tokens.css / tokens.json：追加 3 组调色板 + 3 组 status 别名（indigo / orange / rose，50+700）。
2. visual.css：在 Status 区块补 3 条 .badge[data-tone=borrowed|factory|pendscrap] 规则；neutral 显式命名。
3. SPECIFICATION.md §2/§5：Status 组件从 5 档扩到「生命周期 8 + 异常 3 + 中性」说明；§4 布局补充移动优先断点表（base/576/768/1100）。

可选：把本文演示的 min-width 移动优先栅格并入 visual.css 的响应式区，替代现有 max-width 写法，使 40 页在 320 起即正确。本增强目录不依赖团队原文件修改即可独立预览。
