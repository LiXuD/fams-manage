## 设计范围

- 视觉方向：浅色企业工作台。深蓝为主操作，灰阶承担结构；绿色仅代表结果成功，橙色表示待处理/注意，红色表示错误或危险；不以颜色单独表达状态。
- 方案比较：延续全灰会弱化操作优先级；深色科技风增加密集表格阅读成本；采用浅色深蓝，兼顾长时间使用与现场确认。此为设计建议，待视觉评审。
- 组件：Button、Field、Status、Navigation、TableRow、Notice、Quantity、AssetCard；每类建立原生组件、变体与文字属性，并绑定本地语义变量。
- 页面应用：本地视觉层覆盖全部 40 页；重点截图涵盖 P02/P03/P12/P16、M02/M09/M11/M12。Figma 页面应用仍待完成，不声称云端已有 40 张高保真图。
- 交互规格：焦点、禁用、加载、错误、空态、只读、离线/回执、部分完成与责任边界。
