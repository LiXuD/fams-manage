# D6-16 盘点任务与快照

状态IN_PROGRESS，2026-10-14启动；进度以开发计划§四.5为唯一台账。

依据PRD V1.5 PRD-INV-001/002与AC-20。依赖D6-06、D6-09A、D6-10A已具备本地底座。D6-15独立复核仍待完成，不构成本项底座依赖。

## 本次实现边界

资产管理员组合筛选并预览，创建/修改/删除草稿，发布冻结集合、资产版本及完整责任快照；待入库和未发布期初资产排除。发布不改变资产责任、最近盘点日期或取得资产业务锁。

任务持久状态DRAFT→READY→IN_PROGRESS，开始时间自动恢复或管理员手动开始；逾期仍进行中。未有结果可带原因取消，有结果只能终止。终态不重开，可复制范围。采集、离线、差异复核和封存属于D6-17/18，不能以占位接口冒充完成。

每资产一名主执行人，分配/重分配保存前后人、版本及原因，已盘项必须明确复盘。原参与关系保留以供后续旧授权证据复核，安全撤销不绕过。普通执行人仅见自己的最小快照，不暴露全员联系方式。

## 所有权与一致性

盘点域拥有任务、快照、分配和事件；通过资产域公开的版本化只读投影捕获，不访问其私有实现。发布及分配使用任务锁、当前身份及原键重试，事件/审计/回执同事务。期初导入回滚通过资产域公开下游引用端口检查已发布快照，防止取消被引用资产；不制造跨域bean循环。

结构基线为自有一次性MySQL 8.4.11候选V30共81表的SHOW CREATE TABLE与metadata，不是生产数据。使用新增V31扩展迁移，既有V1–V30不变。验证新库、填充V30升级、重复迁移、失败原子性、并发、重启及恢复；撤回应用不可抹除已发布快照，优先向前修复。

## 可验证完成条件

真实管理员页面完成范围预览→发布→分配→开始；执行人隔离查看；无结果取消和终态拒绝；旧版本/原键重试、身份失效、发布后资产流转不改快照、期初回滚保护及恢复均达到HTTP与数据库持久化证据。统一产品门禁通过后送独立复核，不由实施者代签DEV_VERIFIED。

## 跨域公开契约

fams_asset_inventory_source_v1为资产域拥有的版本化SQL只读投影，公开资产标识/版本、可筛选维度与完整正式责任快照，排除未发布及待入库，不含联系方式、密文或标签秘密。盘点域仅从此投影捕获其私有快照；REPEATABLE_READ的单条INSERT SELECT持有源共享锁，和期初回滚的资产排它锁协调。回滚通过资产域AssetDownstreamUsePort由盘点数据库适配器提供当前锁定读取，不将导入模块耦合到盘点私表或创建服务循环。任务/分配/审计/回执共同事务。

任务wide captured_result_count为后续真实采集的取消保护边界，含手工/任务外发现；D6-16不提供采集占位入口。管理员之外不返回此全任务计数。请求指纹使用固定字段顺序，不依赖JVM的Map.of迭代顺序。V31尚未发布，曾应用的全部环境均为本轮一次性数据库；每轮修改后均已移除并从新库验证。

当前定向7项HTTP（含撤权、开始并发、原生处理器真实HTTP、手工结果边界）及填充升级1项通过，Web32、mini53及类型/构建通过，SpotBugs0。PC跨角色及两次SIGKILL恢复已记录；最终固定候选完整门禁与非实施者复核仍待完成。
