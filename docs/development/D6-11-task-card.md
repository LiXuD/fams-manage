## 业务边界

- PRD V1.5 §7.2、PRD-USE-001/002 与 IA F03/P09/P10/P11/P12/M03/M04 为依据。
- 申请人填类别、规格、数量、用途、期望日和合法目标，不选库存编码。
- 五个结果桶互斥且合计等于申请数量；已分配量 = 待交接 + 已完成。
- 分配保持资产在库事实，通过既有全局资产业务锁阻止重复分配。
- 批准版本/范围、无法满足原因与库存查询摘要、旧分配和再申请来源永久留痕。
- 接收、实物交出、收回取消属于 D6-12；本任务不提前写入在用责任事实。
- 真实短信与真机联调按用户要求待全部功能开发后执行；本地内部验证不替代远端 CI/QA/生产。
