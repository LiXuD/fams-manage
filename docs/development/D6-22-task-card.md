# D6-22 报废与处置任务卡

执行依据为 PRD V1.5 §8.9、§7.5～7.6 与 AC-09/17/26/27/29/30/31，页面按 IA D0.2 的 P20、M03/M05/M07 接续。状态明细维护在第六阶段开发计划 §四.5 的 D6-22A～E，独立复核和完整联合验证满足后才能关闭父任务。

## 业务结果

合法独立来源提交进入待报废并取得活动锁，管理员单次批准只授权处理范围。当前唯一处理库管核验实物或已遗失证据后执行，资产才进入已报废。处置记录独立承担责任、位置、计划日期和后续凭证，保留报废申请的最终事实。

维修、返厂收旧和已遗失来源通过所属域公开端口交接原活动锁，保存源快照和恢复入口。报废执行前保持未关闭借用，执行时由借用所有者关闭遗失借用。驳回恢复必须核对合法的责任和位置，失效时保留冻结并进入受控纠正。

未处置误报废通过新的冲正批准与实物执行恢复。已经处置的普通冲正被拒绝。报废遗失后找回登记临时保管，沿新纳管批准和实物验收恢复原卡，保留遗失核销及原借用终止事实。
